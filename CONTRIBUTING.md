# Contributing

Thanks for helping with TTRPG Content Generator. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug

Open an issue and include:
- your Obsidian version, and whether it happened on desktop or a phone or tablet;
- what you did and what you expected;
- for a custom generator, the generator note (or the part that misbehaves) and any message from **Settings › Custom generators**;
- any error from the developer console (Ctrl+Shift+I on Windows and Linux, Cmd+Option+I on macOS).

## Setting up

```bash
git clone https://github.com/Gregory-Jagermeister/TTRPG-Content-Generator.git
cd TTRPG-Content-Generator
npm install
npm run dev
```

Put (or link) the folder in a **test vault**'s `.obsidian/plugins/` folder, turn the plugin on, and reload Obsidian after each build. Please don't develop in a vault you care about.

## Before you open a pull request

- `npm run lint` passes (it includes Obsidian's own plugin rules).
- `npm test` passes, and new behaviour has tests. The pattern engine (`generators/engine.ts`) and the panel's logic (`editor/panelModel.ts`) are plain functions on purpose, so they can be tested without Obsidian.
- `npm run build` works.
- Keep one change per pull request, and say what it fixes or adds.

## Style

- UI text uses sentence case ("Add a starter set", not "Add A Starter Set").
- Style with CSS classes and Obsidian's theme variables in `styles.css`, never hard-coded colours or inline styles, so themes keep working.
- Build the page with `createEl` / `createDiv`; never `innerHTML` with text that came from a note or a user.
- Messages and docs in plain English: short sentences, examples over jargon.

## Content: words, names and tables

- Don't copy code, art or word lists under the GPL or any other licence that doesn't allow it.
- Never add tables or text from published rulebooks or sourcebooks.
- New words for the built-in generators or starter sets need a source you can name: your own writing, or public-domain data (say which).
- The starter sets are generated by a separate kit builder; open an issue before changing `generators/starters.ts` by hand.
